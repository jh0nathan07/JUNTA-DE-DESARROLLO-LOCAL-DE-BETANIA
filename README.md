Descripción del proyecto
El Sistema de Gestión de Proyectos es una aplicación desarrollada en Python para facilitar la administración y seguimiento de proyectos de la Junta de Desarrollo Local de Betania.
El sistema permite registrar usuarios, crear proyectos, administrar tareas, asignar responsables y registrar el porcentaje de avance de cada tarea.
Además, el sistema calcula automáticamente el avance general de cada proyecto y permite consultar informes y publicar un resumen de los proyectos registrados.


¿Qué problema resuelve?

El proyecto busca solucionar la necesidad de llevar un mejor control de los proyectos y las tareas que forman parte de ellos.

Sin un sistema de gestión, puede resultar más difícil llevar un seguimiento organizado de:

Los proyectos existentes.
Las tareas de cada proyecto.
Los responsables de cada tarea.
El estado de las tareas.
El porcentaje de avance.
El progreso general de cada proyecto.

Este sistema centraliza esta información y permite consultarla desde un menú sencillo.

*Requisitos*
Para ejecutar el proyecto se necesita:

Python 3.x
Un editor de código compatible con Python, como:
Visual Studio Code
PyCharm
IDLE
Thonny

No es necesario instalar librerías externas, ya que el proyecto utiliza únicamente funcionalidades incluidas en Python.

*Instalación*
1. Clonar el repositorio

Desde una terminal se puede clonar el repositorio utilizando:

git clone URL_DEL_REPOSITORIO

Luego entrar a la carpeta:

cd NOMBRE_DEL_PROYECTO
2. Verificar Python

Comprobar que Python esté instalado:

python --version

También puede utilizarse:

python3 --version
Ejecución

Una vez descargado el proyecto, ejecutar el archivo principal:

python Escenario 5.py

Al iniciar el programa aparecerá el menú principal:

=============================================
 SISTEMA DE GESTIÓN DE PROYECTOS JDL
=============================================
1. Registrar usuario
2. Crear proyecto
3. Crear tarea
4. Asignar responsable
5. Registrar avance
6. Ver informes
7. Publicar proyectos
8. Salir
=============================================
Seleccione una opción:

El usuario puede seleccionar la opción correspondiente y seguir las instrucciones del programa.
